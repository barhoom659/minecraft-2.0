# Minecraft 3D

A 3D voxel-based building game inspired by Minecraft.

## Features

- 3D world with block placement and destruction.
- First-person camera controls.
- Basic block types: grass, dirt, stone, wood.
- Inventory system.

## How to Play

- WASD to move.
- Mouse to look around.
- Left click to break blocks, right click to place.
- Number keys to select blocks.

## Technologies

- Three.js for 3D rendering.
- HTML5 Canvas for UI.
